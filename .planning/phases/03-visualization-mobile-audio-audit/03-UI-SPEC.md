# Phase 3 — UI Design Contract

> Visual and interaction contract for the visualization layer (lattice, tonality diamond, scale-on-keyboard), `.kbm` I/O extension to `sclIo`, mobile Safari audio audit, and the floating Stop-all-audio control. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Tech context:** Vanilla TypeScript + Observable Framework. No React, no shadcn, no Tailwind. All design tokens come from Framework's auto-loaded `default.css` (CSS custom properties). UI-SPEC inherits Phase 2's established system; Phase 3 extends it for SVG viz + mobile responsiveness.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (vanilla CSS + Observable Framework theme tokens) |
| Preset | not applicable |
| Component library | none (DOM-factory pattern per ARCHITECTURE Pattern 2; D3 v7 for SVG primitives + zoom; ji-lattice@0.3.2 for coordinate output only) |
| Icon library | none — typographic glyphs only (`▶` for play, `⏵⏵` for arpeggiate, `⏹` reserved for stop, `font-variant-emoji: text` to suppress emoji substitution) |
| Font | Framework defaults: `var(--sans-serif)` for chrome/labels, `var(--monospace)` for ratios/numbers/cents. No custom @font-face. |

**shadcn gate:** Skipped — project is not React/Next.js/Vite (Observable Framework is a static-site generator with reactive Markdown cells, not a React app). Design system is plain CSS with Framework theme tokens, established in Phase 2 and reused here.

**Source of theme tokens:** `--theme-background`, `--theme-foreground`, `--theme-foreground-alt`, `--theme-foreground-focus`, `--theme-blue`, `--theme-green`, `--theme-orange`, `--theme-red`, `--sans-serif`, `--monospace` — all auto-loaded by Framework's `default.css`. Never hard-coded hex values.

## Spacing Scale

Declared values (multiples of 4, all members of the standard set {4, 8, 16, 24, 32, 48, 64}):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline padding, icon gaps, tight glyph spacing |
| sm | 8px | Compact element spacing, button-internal padding (vertical), default row gaps |
| lg | 16px | Default block spacing, button-internal padding (horizontal), viewport padding on narrow screens |
| xl | 24px | Section padding (`.audio-panel`, `.scl-io`, viz widget block margins) |
| 2xl | 32px | Major section breaks between viz widgets on dashboard |
| 3xl | 48px | Reserved (no current Phase 3 use) |

**Exceptions:**
- **Touch targets ≥ 44×44px** (per D-16, mobile audit): floating Stop button, keyboard widget keys, lattice/diamond click hit-areas. The floating Stop button uses padding to reach 44×44 even when the visible chrome is smaller.
- **Viewport padding on narrow screens** = 16px (`lg` token) per D-17, implemented via the dashboard wrapper, not added per-widget.
- **Inline-text spacing** in `.ratio-pill` uses 2–4px gaps (sub-grid; intentional inline-flex baseline alignment).

## Typography

Sizes are 4 declared steps; weights are 2. Matches Phase 2; new viz widgets MUST NOT introduce a 5th size or 3rd weight.

| Role | Size | Weight | Line Height | Family |
|------|------|--------|-------------|--------|
| Caption / helper | 13px | 400 (regular) | 1.5 | `var(--sans-serif)` |
| Body / control | 14px | 400 (regular) for selects/inputs/status; 600 (semibold) for buttons + labels | 1.5 (text), 1.2 (buttons) | `var(--sans-serif)` |
| Numeric / monospace | 14px | 400 | 1.5 | `var(--monospace)` — used for ratios, cents, frequencies, filenames |
| Heading (h2) | inherits Framework default (~20px) | 600 | 1.2 | `var(--sans-serif)` |

**Caption vs. body hierarchy contract:** caption (13px) and body (14px) are only 1px apart. To make the difference read as hierarchy rather than as inconsistency, helper/caption text MUST carry a non-size distinction in addition to the smaller size. Implementation: caption-role text uses the existing `.dashboard-helper` class which applies `color: var(--theme-foreground-alt)`. Captions MUST NOT appear at the same color as body. (Weight stays 400 for both; color is the discriminator.) This rule applies to: helper text under viz headings, the iOS mute-switch hint, the "Use baseHz instead" toggle helper, SVG cents-from-12tet labels.

**Phase 3 specifics:**
- **SVG text labels** (lattice node labels, diamond cell labels, keyboard cents-from-12tet labels): 11–13px in `var(--monospace)`. Cents labels show signed values at **0.1¢ precision** per Phase 2 D-06 and Pitfall #16 (e.g., `+3.9¢`, `−13.7¢`). Cents-deviation labels MUST use `var(--theme-foreground-alt)` (caption color) so they read as secondary annotation, consistent with the caption/body hierarchy contract above.
- **Inputs MUST be `font-size: 16px` minimum on iOS** to suppress Safari's auto-zoom-on-focus (D-17). Apply via media query targeting `@supports (-webkit-touch-callout: none)` OR globally — global is simpler and harmless on desktop. Override the existing 14px in `audio-panel__select`, `scl-io__filename`, baseHz number input only on touch devices, OR raise all inputs to 16px globally (recommended for simplicity).
- **Heading line-height 1.2** for the dashboard h2s ("Audio", "Lattice", "Tonality diamond", "Keyboard", "Scala / KBM I/O").

**Forbidden:** `font-size: 12px` or smaller for any interactive control; italic for emphasis (use weight only); custom font stacks beyond `--sans-serif` and `--monospace`.

## Color

Phase 3 inherits Phase 2's three-color contract using Framework theme tokens. The 60/30/10 split applies to **paint area**, not to layout-level surface counts.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--theme-background)` | Page background, default control fill, SVG canvas |
| Secondary (30%) | `var(--theme-foreground)` (text) + `color-mix(in oklab, currentColor 6–12%, transparent)` (borders, dividers) | Body text, table cell borders, control borders, scale-table dividers |
| Accent (10%) | `var(--theme-blue)` | **Reserved for the list below — never generic interactive elements.** |
| Destructive | `var(--theme-red)` | `.dashboard-error` block; reserved otherwise |

**Accent (`--theme-blue`) is reserved for:**
1. Primary action button text and focus state — `play`, `arpeggiate`, drone-toggle button label, `Download .scl`, `Download .kbm`, lattice/diamond/keyboard click affordances.
2. Active-state tints — drone toggle (`aria-pressed="true"`) gets a 12% blue tint over background; in-scale lattice nodes / diamond cells get accent tint; pressed keyboard key gets accent tint.
3. **Floating Stop-all-audio button** (Phase 3, D-16): uses `--theme-red` instead — it's a destructive recovery action, not a primary CTA. (Override of Phase 2 accent rule — explicitly destructive semantics.)

**NOT accent-colored:** import buttons, filename inputs, baseHz number input, "Use baseHz instead" toggle (uses default control styling), generic select chrome, status-region text.

**Viz-specific colors (Phase 3 introduces a 3-prime palette inside SVG only):**

| Prime axis | Color | Token |
|-----------|-------|-------|
| Prime 3 | blue | `var(--theme-blue)` |
| Prime 5 | green | `var(--theme-green)` |
| Prime 7 | orange | `var(--theme-orange)` |
| Prime ≥11 | foreground | `var(--theme-foreground)` (graceful fallback; no rainbow) |

All four are Framework theme tokens — no hard-coded hex. The palette is **only used inside lattice nodes and diamond cells** (D-21, D-22). Outside SVG, the 60/30/10 contract holds: blue is the only accent in chrome.

**Contrast requirement:** ALL text (including SVG `<text>` labels at 11–13px) MUST hit WCAG AA contrast against its background. Validate via Framework's light + dark default themes. The `color-mix(... 12% ..., var(--theme-background))` accent tints meet AA when paired with `var(--theme-foreground)` text per existing Phase 2 audit.

| Error — file too large | `File exceeds 1 MB cap. Trim or split before importing.` |
| Error — audio context blocked (mobile fallback hint) | `Audio is suspended. Tap any play button to resume.` |
| iOS mute-switch hint (tooltip / inline note on dashboard) | `If you hear nothing on iPhone, check the silent switch on the side of your device.` |

**Destructive actions in this phase:**
- **Stop all audio** — non-destructive in the data sense (no scale data lost), but it cuts active audio mid-playback. **No confirmation modal** — the whole point is instant recovery from runaway voices (Pitfall #9). Visual treatment uses the destructive color (`var(--theme-red)`) to telegraph "this will interrupt." Always reversible (user can re-trigger any playback button).
- **No other destructive actions in Phase 3.** `.scl` / `.kbm` import replaces dashboard scale state, but Phase 3 doesn't add a confirmation prompt for that — Phase 2 didn't either, and the user explicitly chose the file. Document this as a known trade-off; revisit only if undo becomes a user request.

**Tone:** terse, imperative, concrete. No hedging ("you might want to…"). No exclamation marks. Errors describe what failed and what to check, not what the user did wrong.

## Interaction Contracts

### Lattice (VIZ-01)
- **Render:** D3-managed `<svg class="viz lattice">` with `<g>` per node, `<circle>` + `<text>` for ratio, `<text>` below for signed cents-from-12tet at 0.1¢.
- **In-scale node:** filled with prime-axis color at 100% opacity.
- **Neighbor node** (when `opts.showContext: 'neighbors'`): outlined-only stroke, fill `var(--theme-background)`. Default on dashboard = `'neighbors'` per D-05.
- **Pan/zoom:** `d3.zoom()` on the SVG. Mouse wheel + drag desktop; pinch + drag touch.
- **Click audition:** click any node → call `synth.playNotes` for the dyad `[1/1, ratio]` (default `opts.audition: 'dyad'` per D-07) at the dashboard's `effectiveBaseHz`.
- **Keyboard accessibility:** every `<g class="lattice-node">` gets `tabindex="0"`, `role="button"`, `aria-label="Play {ratio}"`. Enter/Space triggers same audition.
- **Hover/focus state:** outline 2px `var(--theme-foreground-focus)`; offset 2px (matches existing button focus-visible pattern).

### Tonality Diamond (VIZ-02)
- **Render:** D3-managed `<svg class="viz diamond">`. Cells laid out by hand on a `(i, j)` grid for `i, j ∈ odd ints ≤ oddLimit`, octave-reduced to `[1, 2)`.
- **In-scale cell:** filled with the dominant prime's color.
- **Out-of-scale cell** (default `'neighbors'` shows the full odd-limit grid as context): outlined-only.
- **Hover tooltip:** native SVG `<title>` element with `{ratio} | {cents}¢ | {prime-limit}-limit | {in-scale | not in scale}`. (Per D-22; keyboard-discoverable as `<title>` is announced by screen readers when the node is focused.)
- **Pan/zoom:** same `d3.zoom()` treatment as lattice.
- **Click audition:** dyad by default per D-07.
- **Keyboard accessibility:** same pattern as lattice — `tabindex`, `role="button"`, `aria-label`.

### Keyboard (VIZ-03)
- **Render:** `<svg class="viz keyboard">` with N adjacent rectangle keys, one per scale degree (linear-by-degree per D-03; NOT MIDI-anchored).
- **Period boundary marker:** vertical dashed line between key N-1 (period interval) and the implicit key N (first repeat). Stroke `var(--theme-foreground-alt)` at 1px dashed.
- **Cents label above each key:** signed, 0.1¢, `var(--monospace)` 11–13px, color `var(--theme-foreground-alt)`. Examples: `+3.9¢`, `−13.7¢`, `+0.0¢`.
- **Active state** (key currently sounding): fill with `color-mix(in oklab, var(--theme-blue) 24%, var(--theme-background))`. Bound to `synth` note-on / note-off callbacks (per D-23). `aria-pressed="true"` on the key while held.
- **Click audition:** `note` mode (single note, NOT dyad — keyboards play single notes; per D-04). Click → `synth.playNote(scale.intervals[N], effectiveBaseHz)`.
- **Touch-and-hold** for sustained note: `pointerdown` starts, `pointerup`/`pointerleave`/`pointercancel` stops. Mobile-essential.
- **Keyboard accessibility:** each key `tabindex="0"`, `role="button"`, `aria-label="Play degree {N}: {ratio}, {cents}¢ from 12-TET"`. Enter/Space triggers a fixed-duration note (e.g., 600ms — matches existing `playInterval` widget).

### Combined `sclIo` (IO-03 extension)
- **Import button:** label `Import .scl or .kbm…`. File picker accepts `.scl, .kbm` extensions; format auto-detected by extension on the `File.name` (case-insensitive).
- **Export row:** two buttons side-by-side: `Download .scl` and `Download .kbm`.
- **Filename input:** unchanged from Phase 2 (default `scale-{N}-tone-{YYYY-MM-DD}`); the extension shown next to the input updates based on which export button the user is hovering — OR (simpler, recommended) drop the trailing `__filename-ext` span and let each button append its own `.scl` / `.kbm` to the user-typed filename. Recommend the simpler path.
- **Status region:** single `role="status" aria-live="polite"` (existing). Messages exact per copywriting table.

### Floating "Stop all audio" button (D-16)
- **Position:** `position: fixed; top: 16px; right: 16px;` on desktop. On narrow screens (`max-width: 480px`), `top: 16px; right: 16px;` with same 44×44 minimum. (Single 16px value matches the `lg` viewport-padding token; no narrow-screen exception needed.)
- **Visibility:** controlled by a reactive `Mutable<boolean>` keyed off `synth.activeVoices > 0`. When zero, `display: none`. When `> 0`, `display: inline-flex`. (Per D-16; uses existing `synth.activeVoices` getter from Phase 2 INVENTORY.)
- **Esc keybinding:** bound in the synth cell with `document.addEventListener('keydown', ...)` + `invalidation.then(() => removeEventListener)` cleanup (Pitfall #11).
- **Visual:** red outline + red text by default; inverts to white-on-red on hover/focus to convey urgency without being garish.
- **Touch target:** ≥ 44×44px including padding.
- **`aria-label`:** `Stop all audio. Keyboard shortcut: Escape.` Visible label `Stop all audio (Esc)`.

### "Use baseHz instead" toggle
- **Surface condition:** rendered only when `importedKbm !== null`. Empty container otherwise.
- **Default state:** OFF (= use the imported `.kbm`) per D-13.
- **Implementation:** Framework `Inputs.toggle({label: "Use baseHz instead of imported .kbm", value: false})`. Label is the exact copy from the table.
- **Effect:** drives the `effectiveBaseHz` derivation in the dashboard's reactive cell. No visual change to existing widgets — they re-render with the new effective frequency.

### Mobile responsive layout (D-17)
- **Single-column, full-width** below the page's natural max-width. No `@media (min-width:)` breakpoints introduced in Phase 3.
- **Viewport meta:** confirm `<meta name="viewport" content="width=device-width, initial-scale=1">` is present in Framework's HTML shell (it is — Framework default).
- **Inputs `font-size: 16px`** globally to prevent iOS auto-zoom.
- **Viewport padding** = 16px (`lg` token) at all widths. No narrow-screen reduction.
- **No horizontal overflow** at viewport widths ≥ 320px. Each viz SVG must shrink gracefully via `width: 100%` + `preserveAspectRatio`.
- **Touch targets** for keyboard widget keys, lattice/diamond clickable nodes/cells, Stop button: ≥ 44×44px effective hit area (use SVG `pointer-events` + invisible padding-rect if visual size is smaller).
