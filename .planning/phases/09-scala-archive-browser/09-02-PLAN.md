<objective>
Build the archive-browser widget (LIB-01 surface + LIB-02 audition): a Pattern-2 DOM factory
`generateArchive(synth, opts) => HTMLElement` that browses + debounced-searches the bundled archive
index (from 09-01), and on selection loads the chosen scale into a tempered-aware scaleTable + ⏵⏵ Play
for audition. It exposes `getScale()` / `isTempered()` exactly like every other generator widget, which
makes the 09-03 Send-to wiring trivial.

Purpose: This is the user-facing browse/search/audition surface. Following the established widget contract
(`generateCs` structurally; `scaleCompare` for the pick-a-named-scale interaction) means the wiring plan
(09-03) is pure plumbing.

Output: `src/components/generate-archive.ts` + happy-dom tests + INVENTORY append.
</objective>

## Decisions (made explicit)

- **D-B1 (lazy load): the archive JSON is fetched via `FileAttachment("scala-archive.json").json()` the FIRST
  time the widget needs it (constructor kicks off the load; a loading state shows until it resolves), NOT at
  page boot.** Rationale: the widget is instantiated once in generate.md but only relevant when the archive
  method is selected; deferring the multi-entry payload keeps page boot light (orchestrator point B).
  `FileAttachment` is a Framework runtime global available inside `.md` cells; the widget receives the loaded
  entries via an `opts.loadEntries` async thunk so the component stays unit-testable WITHOUT FileAttachment
  (the page passes `() => FileAttachment("scala-archive.json").json()`; tests pass an in-memory array).
- **D-B2 (performance — capped incremental list): never render all entries at once.** Render at most
  `DEFAULT_SEARCH_CAP` (50, from 09-01) matching rows + a "showing X of Y" caption; search input is debounced
  (~150 ms) before re-filtering via `searchArchive` (orchestrator point D).
- **D-B3 (tempered-aware preview): on select, parse `entry.degrees` via `parseScala`, build a `Scale`, and render
  `scaleTable(scale, baseHz, { tempered: entry.tempered })` + `playScale(scale, synth, { baseHz })`.** The
  per-entry `tempered` flag (09-01 D-A4) drives the cents-only display AND is returned by `isTempered()` so
  Send-to serializes cents-per-line for tempered scales (SURF-06) — never laundered as ratios.
- **D-B4 (XSS — T-02-14 precedent): archive `name`/`filename` are attacker-influenced text (third-party `.scl`
  descriptions); render EVERY dynamic value via `createElement` + `textContent`, never `innerHTML`.**

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| archive entry text → DOM | `name` / `filename` originate from third-party `.scl` descriptions — attacker-influenced text rendered in the browse list. |
| search input → filter | user search text drives `searchArchive`; must not become a DOM/HTML sink. |
| entry.degrees → parseScala | pre-validated at build time (09-01), but the widget re-parses on select; a parse error must not crash the widget. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-03 | Tampering / Info disclosure (stored XSS) | rendering archive name/filename in the list + selected-scale description | mitigate | EVERY dynamic value rendered via createElement + textContent, never innerHTML (D-B4 / T-02-14 precedent); `grep -c innerHTML` gate == 0. |
| T-09-04 | Denial of Service | rendering thousands of rows / unbounded search | mitigate | list capped at DEFAULT_SEARCH_CAP rows with a "showing X of Y" caption; search debounced ~150 ms (D-B2). |
| T-09-05 | Denial of Service | parse error on select crashing the widget | mitigate | parseScala wrapped in try/catch on select → status-region message + prior preview preserved (D-16 discipline); degrees are pre-validated build-time. |
| T-09-06 | Tampering | tempered scale displayed/exposed as exact JI | mitigate | the per-entry build-time `tempered` flag (09-01 D-A4) drives both the scaleTable cents-only display AND isTempered(); tested for both JI and tempered fixtures (SURF-06). |
</threat_model>
