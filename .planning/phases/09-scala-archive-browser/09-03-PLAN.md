## Decisions (made explicit)

- **D-C1 (single instantiation + lazy load): instantiate `const archiveWidget = generateArchive(synth, { baseHz,
  loadEntries: () => FileAttachment("scala-archive.json").json() })` ONCE** (the persistent-widget Pattern-2
  precedent — closure-local search/selection survives picker swaps). The FileAttachment thunk lazy-loads the
  index only when the widget first needs it (09-02 D-B1), so page boot stays light.
- **D-C2 (picker placement): add an "Archive" family (or an option in a sensible existing family) to
  `METHOD_FAMILIES` with id `archive`.** A new top-level "Scala archive" optgroup is clearest — it is a load
  source, not a generation method. Use the native-`<select>`/optgroup mechanism already in place (D-04 precedent).
- **D-C3 (serializer reuse): the archive `*ScaleText()` serializer branches on `archiveWidget.isTempered()` —
  `centsPerLine` (tempered) vs `ratioPerLine` (exact JI)** — exactly the rank-2 / sonicweave / cs CONDITIONAL
  precedent. This is the SURF-06 correctness branch for archive scales: a tempered (cents-defined) archive scale
  is sent cents-per-line, never laundered as ratios.
- **D-C4 (no new Send-to code): do NOT add archive-specific Send-to logic.** `activeWidgetScale()` gains an
  `archive` branch returning `{ scale: archiveWidget.getScale(), tempered: archiveWidget.isTempered() }`; the
  existing transform strip + `sendCurrentScaleTo` machinery handles the rest unchanged (the LIB-03 "free" win).
