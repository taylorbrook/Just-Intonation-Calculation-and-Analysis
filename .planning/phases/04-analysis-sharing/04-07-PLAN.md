Page hash-read cell pattern (NEW — write into both `src/index.md` and `src/pages/analysis.md`):
```ts
// Hash-read at boot — runs ONCE before the seed-text cell. Reads window.location.hash
// (which starts with "#"); strips the "#s=" prefix; decodes via decodeHashToScale.
// On success, the decoded text becomes the textarea's initial value. On null
// (malformed/oversized/empty), fall back to the seed text and post a status-region
// message per D-20.
const hashRaw = typeof window !== "undefined" && window.location.hash.startsWith("#s=")
  ? window.location.hash.slice(3)
  : "";
const hashDecoded = hashRaw ? decodeHashToScale(hashRaw) : null;
const hashError = (hashRaw && hashDecoded === null)
  ? "Couldn't load shared scale: malformed or oversized hash. Falling back to default."
  : null;
const initialScaleText = hashDecoded ?? seedText;
```

Page hash-write cell pattern (NEW — write into both pages):
```ts
// Hash-write — debounced 300ms (D-17 / D-26). Runs whenever scaleText changes.
// Uses history.replaceState (NOT pushState) so back-button history stays clean.
// Catches encodeScaleToHash's RangeError on > 8KB input — surfaces in the status
// region instead of crashing the cell.
{
  let timer = null;
  const debouncedWrite = () => {
    clearTimeout(timer);
    timer = setTimeout(() => {
      try {
        const hash = "#s=" + encodeScaleToHash(scaleText);
        history.replaceState(null, "", hash);
      } catch (err) {
        // Cell-level surface: console.warn + skip. The status region (in the dashboard's
        // sclIo or a dedicated dashboard status cell) is the user-visible channel; for
        // the dashboard we keep this silent (the hash just doesn't update for huge
        // inputs — re-shareable below 8 KB).
        console.warn("encodeScaleToHash failed:", err);
      }
    }, 300);
  };
  debouncedWrite();
  invalidation.then(() => clearTimeout(timer));
}
```
