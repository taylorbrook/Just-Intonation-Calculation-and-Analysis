    IMPLEMENTATION NOTES:
    1. **buildMos**:
       - Validate: `period.fraction.compare(new Fraction(1n, 1n)) <= 0` -> throw `RangeError("MOS period must be > 1/1")`.
       - Validate: `size >= 1` (and `size <= 1024` defense-in-depth cap) -> throw `RangeError("MOS size must be >= 1")` / `RangeError("MOS size too large (max 1024)")`.
       - Build raw stack: `let cur = new Interval("1/1"); const stack = [cur]; for (let i = 0; i < size; i++) { cur = cur.mul(generator); stack.push(cur); }`. (size+1 entries; the [0] is 1/1, rest are accumulated stacks.)
       - Period-reduce each: `const reduced = stack.map(iv => iv.octaveReduce(period));`
       - Sort ascending by cents: `const sorted = [...reduced].sort((a, b) => a.cents - b.cents);`
       - Dedupe by BigInt Fraction equality (NEVER cents): `const deduped: Interval[] = []; for (const iv of sorted) if (!deduped.some(d => d.equals(iv))) deduped.push(iv);`
       - Ensure trailing period: if `deduped[deduped.length - 1].equals(period)` is false, append `period`.
       - Construct: `return new Scale(deduped, period);`. (Scale's own constructor will re-validate period — a defense-in-depth second check.)
    2. **nearestMosSize** — Stern-Brocot continued-fraction convergents of `α = log(generator.fraction.valueOf()) / log(period.fraction.valueOf())` (use `Math.log` — convergent finding is a numeric search, not part of the BigInt math kernel; comment that this is a deliberate Number-precision use):
       - Validate: `period > 1/1` (same as buildMos); `target >= 1` (else throw RangeError).
       - Compute `α` (a float in (0, 1) for typical generators smaller than the period; clamp to (0, 1) by reducing if needed: if `α >= 1`, divide generator by period until in range — equivalent to working with the period-reduced generator's cents/period.cents ratio).
       - Continued-fraction expansion: implement with the standard algorithm — `let x = α; const a = []; for (let i = 0; i < 16; i++) { const ai = Math.floor(x); a.push(ai); const frac = x - ai; if (frac < 1e-12) break; x = 1 / frac; }`.
       - Generate convergents `p_k / q_k` from the `a` array using the standard recurrence: `p_{-1}=1, p_0=a_0, p_k=a_k*p_{k-1}+p_{k-2}`; `q_{-1}=0, q_0=1, q_k=a_k*q_{k-1}+q_{k-2}`.
       - Collect each `q_k` as a candidate MOS size (the denominator of the convergent IS the size).
       - Pick the candidate closest to `target` (`Math.abs(q_k - target)` minimized; if tied, return the smaller for determinism). Return that integer.
       - Cap at 16 convergents — sufficient for any reasonable target (the (3/2, 2/1) sequence reaches 53 by convergent 6, 70 by 7).
    3. **NO `moment-of-symmetry` import**: confirmed by grep before commit.
