<framework_conventions>
- TypeScript imports use `.js` extensions even from `.ts` source files (`import { add } from './example.js'`). This is required for runtime resolution under Framework's transpile.
- Framework transpiles `.ts` → `.js` via esbuild and DOES NOT type-check (Pitfall #12 in PITFALLS.md). `tsc --noEmit` is the only line of defense — it MUST pass in CI.
- Vitest's default test discovery (`*.test.ts` anywhere under `src/`) is fine, but exclude `src/**/*.md` and `dist/**` explicitly to avoid Framework artifacts.
- ESLint 9 uses flat config (`eslint.config.js` at repo root, NOT `.eslintrc`). Type-aware rules require `parserOptions.project: './tsconfig.json'`.
</framework_conventions>
