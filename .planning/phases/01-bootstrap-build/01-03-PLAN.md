<hello_page_design>
<!-- D-14 design — concrete spec so executor doesn't invent. -->

The hello page must:
1. Import `Fraction` from `fraction.js` (NOT from `xen-dev-utils`'s re-export — direct import is more honest about what version we depend on).
2. Construct `new Fraction("81/79")` — verifying string-input parsing.
3. Display the ratio (e.g., `81/79`) AND the cents value rounded to 2 decimal places (`43.21¢`).
4. Use a top-level reactive cell + inline `${...}` interpolation, demonstrating the Framework programming model.
5. Include a tiny "what this proves" prose paragraph so future readers (the user, in a week) understand why this page exists.

Cents calculation:
```typescript
const ratio = new Fraction("81/79");
const cents = 1200 * Math.log2(Number(ratio.valueOf()));
// 1200 * Math.log2(81/79) ≈ 43.2074... cents
```

Rounding: `cents.toFixed(2)` → `"43.21"`.

NOTE on `valueOf()`: fraction.js v5's `Fraction` instance has `.valueOf()` returning a number for math interop. We accept the float here ONLY for the cents display projection (per Pitfall #1 — cents is a display projection, never a source-of-truth). The ratio itself remains exact via the `Fraction` BigInt internals.
</hello_page_design>
