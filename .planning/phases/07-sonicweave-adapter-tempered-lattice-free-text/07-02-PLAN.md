<objective>
Build the two "Regular" optgroup widgets over the Plan-01 adapter: `generate-rank2.ts` (GEN-06) and `generate-welltemp.ts` (GEN-07). Each is a Pattern-2 factory `(synth, opts) => HTMLElement` that composes a SonicWeave source string from typed parameters, calls `scaleFromSonicWeave`, and renders the result. Rank-2 lands on quarter-comma meantone (D-02, conditionally tempered); well-temp lands on Vallotti (D-06, always tempered). Both reuse the Phase-6 tempered table+badge verbatim and surface errors in a status region while preserving the prior preview.

Purpose: These two widgets deliver the rank-2 regular-temperament and historical well-temperament generators — the heart of "tempered, not laundered JI." They are file-disjoint from Plan 03 (Fokker + free-text) and run in parallel; page registration is deferred to Plan 04.
Output: two components + two CSS files + two component tests + the well-temperament per-preset test vectors appended to `sonicweave.test.ts`.
