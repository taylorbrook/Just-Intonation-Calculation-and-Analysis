| Boundary | Description |
|----------|-------------|
| user param input → Scale construction | Segment-size integer param is bounded numeric input; produces exact `Fraction`s via the kernel. No string injection surface. |
| page → store (write) | The two Send-to buttons are the ONLY writers; `writeSharedScale` (Plan 01) enforces the 8 KB cap and validation. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-04 | Tampering (XSS) | All dynamic render on generate.md (picker placeholders, status/error region, Send-to buttons, preview) | mitigate | `createElement`+`textContent` only; `replaceChildren` re-render; NEVER `innerHTML` (grep-gated in the automated verify).
