## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| localStorage → app (read at boot) | Untrusted persisted JSON (`tuning-systems:scale`) crosses into the app; may be tampered, malformed, oversized, or absent. |
| producer → store (write) | The only writer is the Generate page (Plan 02); this plan provides the validated write path with the 8 KB cap as an oversize guard. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Tampering | `readSharedScale` parsing `localStorage["tuning-systems:scale"]` | mitigate | Shape validation (`typeof obj.text === "string"`), reject array/primitive/non-object, `JSON.parse` inside try/catch → `null`. Mirrors `readThemePrefs` T-9mn-01. ASVS V5 input validation. |
| T-05-02 | Denial of Service | Oversized stored/sent scale text | mitigate | 8 KB cap (`MAX_SCALE_TEXT_BYTES`, UTF-8 byte length) enforced on BOTH read and write; oversized → `null` read / silent-no-op write. Single source of truth shared with `url.ts`. |
| T-05-03 | Information disclosure | `localStorage` throws in private browsing / disabled storage | mitigate | All read/write wrapped in try/catch → `null` / silent no-op; never throws, never crashes boot. Mirrors `readThemePrefs` T-9mn-03. |
| T-05-04 | Tampering (XSS downstream) | Stored scale text rendered later | mitigate (defense-in-depth here) | Store keeps text as a string only; rendering is via `createElement`+`textContent` / `scaleTable` / textarea `.value` in Plans 02–03 — never `innerHTML`. This plan introduces no render path. |
| T-05-SC | Tampering | npm/pip/cargo installs | accept | Phase 5 installs ZERO packages (RESEARCH Package Legitimacy Audit: N/A). No new dependency surface; no legitimacy checkpoint required. |

All threats are mitigated except T-05-SC (accepted: no packages added). No HIGH-severity threat is left unmitigated.
