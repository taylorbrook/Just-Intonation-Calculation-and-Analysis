Unify the over-cap contract and apply four low-risk hardening fixes across the URL / share / IO layer of the Tuning Systems notebook.

| Boundary | Description |
|----------|-------------|
| URL hash -> page cell | Untrusted hash text crosses into the decoder (already mitigated upstream: decodeHashToScale never throws, caps at 16 KB, textContent-only render). |
| another tab's localStorage write -> open tab | Cross-tab `storage` event delivers an attacker-influenceable `e.newValue`; this plan deliberately re-reads via `readSharedScale()` (validates shape + 8 KB cap + never throws) instead of trusting `e.newValue`. |
| user-typed filename -> download `a.download` | Untrusted name string composed into a filesystem-bound download name; sanitized here. |
