# Quick task 260514-9o5 — Summary

## What was wrong

The "Tenney-weighted error in the EDO ranker" section on
`src/pages/tenney-height.md` (line 273) used a ` ```js ` fence to display a
two-line excerpt from `src/lib/edo.ts`. Observable Framework executes any
`js`/`ts` fenced block as a reactive cell, so it tried to run:

```
const weight = Math.max(1, tenneyHeight(iv.monzo));
tenneyWeighted += absCentsError / weight;
```

`tenneyWeighted` is not declared in page scope. Framework rejected the cell
with `SyntaxError: Assignment to external variable 'tenneyWeighted' (2:0)`,
blocking the page from rendering past that point.

## Fix

Changed the fence on line 273 from ` ```js ` to ` ```ts run=false ` — the
existing project convention for display-only code (see `odd-limits.md` lines
321 and 329). The snippet now renders as syntax-highlighted source instead
of being evaluated. Block contents are unchanged.

The page's other `js` block at line 327 (`furtherReading([...])`) is a real
self-contained reactive cell and was left untouched.

## Verification

- One-line fence change; no behavior shift expected anywhere else on the page.
- Visual / runtime verification is human: confirm `/pages/tenney-height`
  renders cleanly with no console error after `npm run dev`.
