# Quick 260513-9s8: Well-temperament theory page Summary

New theory page (`/pages/well-temperament`) covering Werckmeister III (1691), Kirnberger III (1779), and Vallotti (1779) — the historical bridge between meantone and 12-EDO, with key-character made visible (per-temperament fifth-size + major-third Plot bar charts) and audible (six triad-audition buttons).

  - H1 + tagline, single imports cell, single synth cell (`createSynth()` + `invalidation.then(synth.dispose)`), prerequisite aside pointing to `./meantone` and `./pythagorean-comma`.
  - Kernel-exact anchors cell: `pureFifth = new Interval("3/2")`, `pythComma = commaByName("Pythagorean comma")!`, `syntonic = commaByName("syntonic comma")!`, `schisma = commaByName("schisma")!`, `pure5Third = new Interval("5/4")`, `pythThird = new Interval("81/64")`.   - Three 12-entry per-temperament fifth-size arrays (`werckFifths`, `kirnFifths`, `vallottiFifths`), each summing to 8400.000000000¢ exactly (closure invariant; sanity-checked at task verification).

  - **One `playTriadAt(label, rootCents, thirdCents, fifthCents)` factory** mirroring meantone.md's `playTempered`. Six button instances: C-major and F♯-major triads × three temperaments. baseHz = 440 (D-08), duration = 1.5s (D-18). All audio via the page-level `synth`.
  - Prose: two-paragraph opening, `## The construction (general)` with the 8400¢-closure KaTeX identity and the `PC = SC + schisma` algebraic identity that explains Kirnberger's mixed split.

  - `## Audition` H2 with the six buttons laid out as 3 × 2 (one row per temperament).
  - `## How well-temperaments compare` — plain-DOM 5-column comparison table built from each `*Thirds` array's min/max key. **Cleanest / roughest cents derived from the same kernel-anchored arrays the charts use** (no hardcoded values).
  - `## Why this matters` — three-paragraph synthesis (WTC, meantone→well-temp→12-EDO arc, Wagner D♭-major as residual key-character).
  - `## See also` linking forward to `/pages/edo-approximation` and backward to `/pages/meantone`, `/pages/pythagorean-comma`, `/pages/syntonic-comma`, and `/` (dashboard).

### Additions / clarifications beyond the literal plan steps

- **Step 9 typography**: The plan describes label `dy` as a static integer in the Plot.text marks. The final code uses `dy: (d) => (d.dev < -0.01 ? 12 : -8)` so that label numbers sit *below* tempered-flat (negative) bars (which point downward) and *above* zero bars — better legibility. Pure visual polish; no semantic change.
- **Step 12 comparison table**: Cents min/max for the "Cleanest key" / "Roughest key" columns are computed in-cell from each `*Thirds` array (`reduce((a,b) => a.cents < b.cents ? a : b)`) — they update automatically with the kernel anchors. The plan said "derived from the per-temperament `*Thirds` arrays (min and max)"; this is the literal implementation.
