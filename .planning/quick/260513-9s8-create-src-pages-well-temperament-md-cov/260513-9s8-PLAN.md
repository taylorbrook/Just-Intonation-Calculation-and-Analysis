7. **Major-third-per-key helper.** Build a small function that takes a fifth-size array and returns a 12-row `{key, majorThird}` array. The major third of key K is `(fifths[i_K] + fifths[i_K+1] + fifths[i_K+2] + fifths[i_K+3]) - 2400`, where indexing walks the circle starting at C (positions 0..11 = C,G,D,A,E,B,F♯,C♯,G♯,E♭,B♭,F) and wrapping mod 12. Use the existing meantone.md `tempered(n)` cents-math pattern as a model — pure cents arithmetic, no `new Interval(...)` allocations for the irrational tempered third.

   Cumulative-cents helper (for triad audition later — see Step 11):
   ```ts
   const KEYS = ["C","G","D","A","E","B","F♯","C♯","G♯","E♭","B♭","F"];
   function cumulativeAt(fifths, keyIndex) {
     let c = 0;
     for (let i = 0; i < keyIndex; i++) c += fifths[i].cents;
     return ((c % 1200) + 1200) % 1200;          // reduce into [0, 1200)
   }
   function majorThirdAt(fifths, keyIndex) {
     // 4 consecutive fifths starting at keyIndex, then drop 2 octaves.
     let sum = 0;
     for (let k = 0; k < 4; k++) sum += fifths[(keyIndex + k) % 12].cents;
     return ((sum - 2400) % 1200 + 1200) % 1200;
   }
   const werckThirds     = KEYS.map((k, i) => ({ key: k, cents: majorThirdAt(werckFifths,     i) }));
   const kirnThirds      = KEYS.map((k, i) => ({ key: k, cents: majorThirdAt(kirnFifths,      i) }));
   const vallottiThirds  = KEYS.map((k, i) => ({ key: k, cents: majorThirdAt(vallottiFifths,  i) }));
   ```
