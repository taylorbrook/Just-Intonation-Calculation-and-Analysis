# Quick Task 260513-kb6 — CMD-3: spiralOfFifths onStepClick

## Goal

Wire the existing `onStepClick?: (step: SpiralStep) => void` prop (added to
`spiral-of-fifths.ts` in 260513-jir / commit `b469080`) on the two pages
that render a spiral: `src/pages/pythagorean-comma.md` (pure 3/2 branch)
and `src/pages/meantone.md` (1/4-comma tempered branch). Each spiral node
becomes a click-to-audition button playing the dyad `[440, 440 × ratio]`
for 1.5s — the same shape `playInterval` writes to the synth (D-07 dyad /
D-18 1.5s). `pythagorean-tuning.md` is intentionally excluded — the
260513-foy audit confirmed it uses `scaleTable`, not `spiralOfFifths`.

## Approach — page-side closures over the page's existing synth cell

Both pages already have a top-level `createSynth()` cell (mirrored from the
`monzos.md` pattern with `invalidation.then(() => synth.dispose())`). The
viz component stays viz-only — D-08 / Pitfall #2 — and the audition wiring
lives inline at the call site, capturing `synth` from the page scope.

**pythagorean-comma.md (pure branch):** every `step.ratio` is a non-null
octave-reduced `Interval` (the chain runs `acc = acc.mul(3/2).octaveReduce()`),
so the click handler is the same one-liner `playInterval` uses internally:
```ts
synth.playNotes([baseHz, baseHz * Number(step.ratio.fraction.valueOf())], 1.5)
```
A defensive `if (!step.ratio) return` is included — won't fire in the pure
branch but keeps the handler type-safe under `SpiralStep.ratio: Interval | null`.

**meantone.md (tempered branch):** `step.ratio` is `null` (meantone fifth
is irrational). `step.cumulativeCents` accumulates without octave-reduction
(reaches ~8359¢ at k=12), so we octave-reduce before sending to the synth
to keep audition in audible range and matching the spiral's own visual
reading (which renders `cents-from-12-TET` of the octave-reduced cumulative).
The page already imports `centsToRatio` from `src/lib/cents.js` — the
existing `playTempered` factory at line 117–129 uses it for the irrational
1/4-comma major-third audition. Same helper, same audio-boundary discipline:

```ts
const reducedCents = ((step.cumulativeCents % 1200) + 1200) % 1200;
const ratio = centsToRatio(reducedCents);
synth.playNotes([baseHz, baseHz * ratio], 1.5);
```

`baseHz = 440` matches D-08 (the same constant `playInterval` uses). 1.5s
matches D-18.
