Continued-fraction CONVERGENTS + SEMI-CONVERGENTS algorithm (D-13 / 04-CONTEXT line 221):

For `(3/2, 2/1)`: α = log2(3/2) / log2(2/1) ≈ 0.5849625007211562
- Continued-fraction expansion: [0; 1, 1, 2, 2, 3, 1, 5, 2, 23, 2, …]
- Convergents (denominators): 1, 2, 5, 12, 41, 53, 306, …  ← misses 3, 7, 17, 29
- SEMI-CONVERGENTS fill the gaps. For each CF coefficient `a_n` at index n ≥ 1, the
  semi-convergents are `(p_{n-2} + k·p_{n-1}) / (q_{n-2} + k·q_{n-1})` for `k = 1, 2, …, a_n`.
  Setting k = a_n recovers the full convergent; k < a_n yields the "best rational
  approximations of the second kind".
- Yields denominator sequence: 2, 3, 5, 7, 12, 17, 29, 41, 53, 94, 147, 200, 253, 306, …
  ← THIS is the canonical Pythagorean MOS sequence the user expects.

The canonical MOS sizes for (3/2, 2/1) by convention: [2, 3, 5, 7, 12, 17, 29, 41, 53].
This sequence is what musicians reach for; any function called `nearestMosSize` MUST
emit it. Convergent-only sequences (e.g. [2, 5, 12, 41, 53]) are mathematically valid
but musically wrong for the public API.

Reference: https://en.wikipedia.org/wiki/Continued_fraction#Best_rational_approximations
(see "Semiconvergents" subsection).

       ```
       // chainLoFor: pick the lowest offset for the contiguous N-stack window so the
       // post-reduction sorted scale is the canonical "Ionian-like" mode. Lookup-driven
       // because every rotation has an identical step multiset → no metric can pick
       // between modes. Hand-traced against must_haves Test 1 and Test 2 vectors.
       function chainLoFor(generator, period, size):
         // Special case: (3/2, 2/1) — the audited Pythagorean lookup.
         if generator.equals(new Interval("3/2")) && period.equals(new Interval("2/1")):
           const lookup = { 2: 0, 3: -1, 5: -2, 7: -1, 12: -5 }
           if (lookup[size] !== undefined) return lookup[size]
         // Default: centered chain (no tonal-music canonical mode for non-(3/2, 2/1) inputs).
         return -Math.floor((size - 1) / 2)

       function buildMos(generator, period, size):
         // Validate
         if period <= 1/1: throw RangeError("MOS period must be > 1/1")
         if size < 1:      throw RangeError("MOS size must be >= 1")
         if size > 1024:   throw RangeError("MOS size too large (max 1024)")

         // Edge case: generator == period (single-pitch — D-29). The single-pitch
         // early-return is REQUIRED — otherwise every stack reduces to 1/1 and the
         // algorithm would emit the period only after dedupe-and-append, but the
         // status semantics differ ("just the period" vs "1/1 deduped to period").
         if generator.equals(period):
           return new Scale([period], period)

         const chainLo = chainLoFor(generator, period, size)
         const stacks  = []
         for (let k = chainLo; k < chainLo + size; k++):
           let cur = new Interval("1/1")
           if k > 0: for (let i = 0; i < k;  i++) cur = cur.mul(generator)
           if k < 0: for (let i = 0; i < -k; i++) cur = cur.div(generator)
           stacks.push(cur.octaveReduce(period))

         // Dedupe by BigInt Fraction equality (Pitfall #1 — NEVER cents tolerance).
         // Use a Set keyed on canonical "n/d" string for O(N) dedup; equivalent to
         // Interval.equals because Fraction normalizes sign + GCD on construction.
         const seen   = new Set()
         const unique = []
         for (const iv of stacks):
           const key = `${iv.fraction.n}/${iv.fraction.d}`
           if (!seen.has(key)):
             seen.add(key)
             unique.push(iv)

         // Sort ascending by cents (consumer table-display contract — Test 10).
         unique.sort((a, b) => a.cents - b.cents)

         // Append the period if not already the trailing entry (Test 11 — D-14 contract).
         const last = unique[unique.length - 1]
         if (!last || !last.equals(period)):
           unique.push(period)

         return new Scale(unique, period)
       ```

       ```
       function nearestMosSize(generator, period, target):
         if period <= 1/1: throw RangeError("MOS period must be > 1/1")
         if target < 1:    throw RangeError("MOS target must be >= 1")

         // Compute α = log(generator) / log(period); reduce to (0, 1) if needed.
         let alpha = Math.log(Number(generator.fraction.valueOf())) /
                     Math.log(Number(period.fraction.valueOf()))
         // Reduce to (0, 1): if alpha >= 1, take fractional part (octave-equivalent).
         alpha = alpha - Math.floor(alpha)
         if (alpha === 0) return 1  // generator IS the period (or a power of it)

         // Continued-fraction expansion of alpha — capped at 12 terms for safety.
         const cf = []
         let x = alpha
         for (let i = 0; i < 12; i++):
           const ai = Math.floor(x)
           cf.push(ai)
           const frac = x - ai
           if (frac < 1e-12) break
           x = 1 / frac

         // Generate convergent + semi-convergent denominators using the standard
         // recurrence: q_{-1} = 0, q_0 = 1, q_n = a_n * q_{n-1} + q_{n-2}.
         // For each n ≥ 1, emit semi-convergents at k = 1..a_n: q_{n-2} + k * q_{n-1}.
         //   - k = a_n recovers the full convergent q_n.
         //   - k = 1..a_n-1 yields the semi-convergents (gap-fillers).
         const candidates = new Set()  // dedup; some semi-convergents reappear
         let qPrev = 0  // q_{-1}
         let qCurr = 1  // q_0
         candidates.add(1)
         for (let n = 1; n < cf.length; n++):
           const an = cf[n]
           // Semi-convergents at this CF level: k = 1..an
           for (let k = 1; k <= an; k++):
             candidates.add(qPrev + k * qCurr)
           // Advance recurrence: q_{n} = a_n * q_{n-1} + q_{n-2}
           const qNext = an * qCurr + qPrev
           qPrev = qCurr
           qCurr = qNext
           if (qCurr > 100000) break  // safety: targets larger than this are unrealistic

         // Pick the candidate denominator closest to `target`. Tie-break: smaller wins.
         let best = 1
         let bestDist = Math.abs(1 - target)
         for (const c of candidates):
           const d = Math.abs(c - target)
           if (d < bestDist || (d === bestDist && c < best)):
             best = c
             bestDist = d
         return best
       ```
