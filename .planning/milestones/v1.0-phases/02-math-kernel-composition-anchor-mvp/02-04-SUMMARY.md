## Decisions Made

(See `key-decisions` in frontmatter for the full list.) Highlights:

- **`formatRatio` helper added** — fraction.js' `toFraction()` returns `"2"` for `2/1` (drops the denominator for whole-number ratios). The .scl format spec and the scaleTable display both want explicit `2/1`, so `formatRatio(iv) → "${n}/${d}"` reads BigInt n/d directly. This was caught during GREEN iteration when writeScl tests failed expecting `2/1` in serialized output.
- **Cents-source LOSSY contract documented** — parsePitchToken's cents path uses xen-dev-utils' `centsToValue` (Number) + `new Fraction(number)` which is LOSSY by definition (Pitfall #1). The JSDoc explicitly acknowledges this; tests verify `cents` *value* via `toBeCloseTo`, not exact-ratio equality. Round-trip equivalence still holds at Fraction-equality level because the float→Fraction conversion is deterministic.
- **First-token-wins for ratio/cents tokens; bracket-form for monzo** — parsePitchToken takes the first whitespace-bounded token for ratio/cents (which makes F09 trivially robust), but extracts the full `[...>` bracket form for monzo (because monzo components inside the bracket are space-separated).
- **INVENTORY deferred** — per Wave 2 file-ownership, Plan 06 will add the four rows (parseScala, parseScl, writeScl, scalaToCsv) to avoid merge conflicts.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] fraction.js' toFraction() drops the "/1" for whole-number ratios**

- **Found during:** Task 1 GREEN iteration (8 of 42 tests failed on first run)
- **Issue:** The plan's draft used `iv.fraction.toFraction()` for serialization. fraction.js v5 returns `"2"` for `Fraction("2/1")`, not `"2/1"` — so `writeScl` produced files ending in `" 2"` instead of `" 2/1"` and `scalaToCsv` rows contained `"2"` instead of `"2/1"`.
- **Fix:** Added `formatRatio(iv)` helper that reads `iv.fraction.n` / `iv.fraction.d` (BigInt-backed) directly and formats as `${n}/${d}`. writeScl and scalaToCsv both use it. Test assertions for whole-number ratios switched from `.fraction.toFraction()` string-equality to `.equals(new Interval("2/1"))` Fraction-equality where appropriate.
- **Files modified:** src/lib/scala.ts (added formatRatio helper; writeScl + scalaToCsv use it), src/lib/__tests__/scala.test.ts (4 test assertions adapted to use Fraction-equality)
- **Verification:** All 42 scala tests pass; full Phase 2 suite at 131 passing
- **Committed in:** 55189a8
