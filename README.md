# Tuning Systems

A research notebook + JI calculator built as an Observable Framework site — Markdown prose on tuning-systems theory living side-by-side with reactive JavaScript cells that compute, visualize, and audition just-intonation intervals.

## Quickstart

```bash
npm install
npm run dev
```

Open <http://localhost:3000> in your browser.

## Build

```bash
npm run build
```

Produces a static site in `dist/`.

## Live site

Deployed to GitHub Pages: <https://taylorbrook.github.io/Just-Intonation-Calculation-and-Analysis/>
